# MirrorMe Beauty

A simple static website for the MirrorMe Beauty concept.

## Files

- `index.html` — website content and page structure
- `style.css` — colours, layout, typography and responsive styling
- `script.js` — Beauty Finder and Makeup Collection interactions

## Run locally

Open `index.html` in a web browser. The images currently load from Unsplash, so an internet connection is needed to display them.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the top level of the repository (not inside another folder).
3. Open the repository's **Settings**.
4. Select **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site. The website address will appear in the Pages section.

## Important

This is a front-end prototype. The product cards are examples only and do not process orders or payments. The beauty recommendations run in the browser and are not generated by an AI service. A real virtual makeup try-on, customer accounts, saved collections across devices, product inventory and checkout would need additional services and development.
